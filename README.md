# 🚲 Bike Sales Customer Analysis Dashboard – Excel

## 📊 Project Overview

This project analyzes bike buyer data using Microsoft Excel to understand customer purchasing patterns and identify key factors influencing bike purchases.

## 🎯 Objectives

- Analyze customer purchasing behavior
- Identify patterns among bike buyers
- Analyze customer demographics
- Understand factors influencing bike purchases
- Create an interactive Excel dashboard

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- Slicers & Filters
- Dashboard Development
- Data Visualization

## 🔍 Analysis

The analysis focuses on:

- Income
- Gender
- Age
- Marital Status
- Education
- Occupation
- Commute Distance

## 📈 Dashboard

The project includes an interactive Excel dashboard using charts, filters, and slicers to explore customer purchasing trends.

![Bike Sales Dashboard](Screenshot%202026-09-04%20194245.png)

## 💡 Key Insights

The analysis helps identify customer segments and purchasing patterns based on demographic characteristics and commute distance.
